# 📝 To-Do List

Jednoduchá webová aplikace pro správu úkolů postavená na PHP a MySQL.

## Technologie

- PHP
- MySQL
- Bootstrap

## Struktura projektu

```
├── index.php        # Hlavní stránka — výpis úkolů
├── process.php      # Zpracování formulářů (přidání úkolu)
├── delete.php       # Smazání úkolu
├── status.php       # Změna stavu úkolu
├── db.php           # Připojení k databázi
└── css/
    └── style.css    # Styly
```

## Funkce

- ✅ Přidání nového úkolu
- ✅ Smazání úkolu
- ✅ Změna stavu úkolu (splněno / nesplněno)
